# Git Instructions

> **READING PROTOCOL — READ THIS FIRST**
> Read ONLY this file. Do NOT read any other file in `AI_docs/` unless explicitly told to.

## Committing to main

**You may NEVER commit directly to `main`.** You may only commit to `main` when you have been
**EXPLICITLY told to do so** — no exceptions, no assumptions. If you are unsure whether you
have permission, you do not: stop and ask.

## Branches

- **Anytime you make a new feature, you MUST create a new branch first.** Never build a feature
  on `main`.
- **If no branch is stated for a task, you must make a new one.**
- **Do NOT delete branches after you make them.** Branches are kept.

## Committing to other branches

- **You may commit freely to the current branch you are working on.** The approval rule above
  applies only to `main`.

## Commit messages

- Keep commit messages **as simple and clear as possible**. Anyone should understand what a
  commit did from its message alone.

## Merging

- **Merge only when you have been told to merge.**
- Even when told, merge **only if the code is safe and not error-prone.** If the code is
  unsafe or likely to break, do not merge — report the problem instead.
